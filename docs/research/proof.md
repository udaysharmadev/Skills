## Key new intelligence encoded

1. **Mutation Validation (Anti-Vacuous)** — introduces the explicit requirement to break the code (mutation testing) to prove the agent-generated test actually catches failures.
2. **Production-Shaped Mocking** — bans arbitrary static stubs in favor of captured real traffic or production-shaped data, preventing agents from verifying their own hallucinated architectures.
3. **Property-Based Invariants** — directs agents away from brittle example-based testing for critical logic, favoring property generators that catch edge cases agents naturally miss.
