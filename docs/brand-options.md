# Bundle brand options

The repository is currently `udaysharmadev/Skills` — deliberately
generic (the PRD defers the brand to a final naming pass, §16). Renaming the GitHub repo is a user decision; this doc
prepares the choice. Collision status here is **unverified** unless
marked otherwise — each candidate needs the same exact-name audit as the
skills before it wins.

## Requirements

Pronounceable · short · developer-friendly · works in slash-command
culture ("install <brand>") · not corny · not "AI Agent Ultra Pro" ·
ownable · expandable into a visual identity.

## Candidates

| # | Name | Rationale | Collision status |
| --- | --- | --- | --- |
| 1 | **Vibe** | owns the vibe-coding category head-on; "Vibe — 27 skills" reads perfectly | unverified — likely contested |
| 2 | **Instinct** | what the bundle gives an agent; ages better than "skills" | unverified |
| 3 | **Crew** | 27 specialists + a concierge; matches the routing metaphor | unverified |
| 4 | **Bench** | the specialists on your bench, sub in per task | unverified |
| 5 | **Toolkit 27** | descriptive fallback; weak ownability | unverified |
| 6 | **Wingman** | agent-side assistance metaphor | unverified — possibly contested |
| 7 | **Marginalia** | memorable, but vague for discoverability | unverified |
| 8 | **Rodeo** | vibe-coding energy, memorable | unverified |
| 9 | **Standard Issue** | "standard-issue skills for your agent" | unverified |
| 10 | **Adda** | warm, memorable — but non-English and earlier renamed | rejected for consistency with English-only content |

## Recommendation (top 3)

1. **Instinct** — best blend of meaning, ownability and tone; survives
   beyond the "skills" buzzword cycle.
2. **Crew** — directly encodes the architecture (concierge + 26
   specialists); easy logo system.
3. **Bench** — developer-native metaphor, short, clean.

**Do not block v1.0 on branding**: ship as
`udaysharmadev/Skills`, rename at announcement time if a winner passes
its audit.
