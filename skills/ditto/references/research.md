## Source 1

Title: Visual comparisons

Author / Organization: Playwright project

Publication date: Living documentation

Version: Current documentation

URL: https://playwright.dev/docs/test-snapshots

Source type: official docs

What it establishes:
Screenshot comparisons can detect rendering differences, while environment differences can affect output.

What this skill adopts:
Compare at controlled viewports and environments, diagnose mismatches by visual dimension, and explain remaining differences.

What it does NOT establish:
Pixel similarity alone does not prove semantic correctness, accessibility, responsive behavior, or asset rights.

Numbers taken from source:
No universal similarity threshold or iteration count is adopted.

Reverify when:
Screenshot tooling or browser rendering behavior changes.
