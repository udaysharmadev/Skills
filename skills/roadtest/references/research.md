Title: Best Practices

Author / Organization: Playwright project

Publication date: Living documentation

Version: Current documentation

URL: https://playwright.dev/docs/best-practices

Source type: official docs

What it establishes:
Test isolation, user-facing locators, and web-first assertions improve browser-test resilience.

What this skill adopts:
Exercise only critical journeys, isolate state, and distinguish expected negative-path responses from unexpected failures.

What it does NOT establish:
It does not say every 4xx or 5xx response is a defect, or that browser automation replaces product judgment.

Numbers taken from source:
No suite-size target is adopted.
