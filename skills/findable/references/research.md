Title: Understand JavaScript SEO basics

Author / Organization: Google Search Central

Publication date: Living documentation

Version: Current documentation

URL: https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics

Source type: official docs

What it establishes:
Google can render JavaScript, but rendering is queued and other bots may not execute it; server-side or pre-rendering remains robust.

What this skill adopts:
Separate crawlability, rendering, indexing eligibility, metadata, and enhancement validation; verify rendered output.

What it does NOT establish:
It does not promise indexing or ranking, and it does not support saying crawlers never see client-injected metadata.

Numbers taken from source:
No ranking or timing guarantee is adopted.

Reverify when:
