## Source 1

Title: Agent Skills specification

Author / Organization: Agent Skills project

Publication date: Living specification

Version: Current online specification

URL: https://agentskills.io/specification

Source type: official docs

What it establishes:
Skills are discovered from concise name and description metadata, then instructions and resources load progressively.

What this skill adopts:
Route by task intent and load only the smallest useful specialist workflow.

What it does NOT establish:
It does not establish that multi-skill chains outperform direct work.

Numbers taken from source:
Name length is 1 to 64 characters; description length is 1 to 1024 characters; instructions under 5000 tokens and SKILL.md under 500 lines are recommendations.

Reverify when:
The Agent Skills specification changes.
